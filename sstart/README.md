# Retail Python ETL
Complete the TODOs in `src/`. Do not change source files in `provided_data/`.

1. Create a virtual environment.
2. Install: `pip install -r requirements.txt`
3. Copy `.env.example` to `.env` and add local SQL Server values.
4. Run: `python -m src.main --config config/config.json`
5. Test: `pytest -q`
